Agent 框架横向对比：LangGraph、AutoGen 与 CrewAI 怎么选

上一篇我们拿 LangGraph 手搓了一个 Agent。但市面上还有 AutoGen、CrewAI、OpenAI Agent SDK……到底选哪个？这篇不罗列特性，而是从每个框架的核心抽象出发：谁把循环变成图、谁把协作变成对话、谁把团队变成角色表。最后给你一张可直接照抄的选型决策清单。

为什么会有这么多框架

如果你读过本站的 Agent Loop 原理就会明白：所谓 Agent 框架，本质上都在实现同一个东西——"思考 → 决策 → 调用工具 → 观察 → 再思考"的标准循环。区别只在于：循环之外，谁提供了更好的控制点、协作方式和工程配套。

所以选框架不是选"谁更厉害"，而是选你更愿意用哪种心智模型去管理这个循环：是画一张图、发起一场对话，还是排一出角色扮演的戏。

三个框架的核心抽象

框架核心抽象一句话概括
LangGraph有向状态图（节点 + 边 + 条件路由）把循环画成图，每一步都可观测、可打断、可回退
AutoGen对话消息流（多智能体群聊）把协作模拟成一群 Agent 在群里聊天，消息即状态
CrewAI角色 + 任务 + 流程（团队剧本）像组团队一样分配角色，按剧本顺序执行

这三个抽象对应着三种团队协作模式，也正好对应 多智能体协作架构里讲过的编排器、辩论和 Manager-Worker 模式——框架只是把模式固化成了 API。

最小示例对比

同样的需求——"让模型决定要不要调用工具"——三个框架各自的写法：

# LangGraph：定义节点，让条件边决定走哪条路
from langgraph.graph import StateGraph, END

def decide(state):
    if state.get("need_tool"):
        return {"next": "tool"}
    return {"next": "end"}

graph.add_conditional_edges("decide", lambda s: s["next"])
# AutoGen：两个角色对话，工具调用是消息的一部分
from autogen import ConversableAgent

assistant = ConversableAgent(name="assistant", llm_config=llm_config)
assistant.register_for_llm(name="search", description="搜索", function=search_fn)
user = ConversableAgent(name="user", llm_config=False)
user.initiate_chat(assistant, message="查一下最近的新闻")
# CrewAI：角色 + 任务 + 流程，框架负责编排
from crewai import Agent, Task, Crew

researcher = Agent(role="研究员", tools=[search_tool], goal="找到答案")
task = Task(description="回答用户问题", agent=researcher)
Crew(agents=[researcher], tasks=[task], process="sequential").kickoff()

三份代码都在表达同一个 Agent Loop，只是"控制点"放的位置不同：LangGraph 放在节点与边，AutoGen 放在消息，CrewAI 放在任务与角色。

怎么选：决策清单

  • 要上生产、要精细控制（人工审核、断点续跑、灰度发布）→ 选 LangGraph，配合 安全护栏实践；
  • 要快速验证"多个 Agent 互相辩论/合作"的研究想法 → 选 AutoGen；
  • 要做业务流程自动化（客服、内容流水线）、团队里非工程师也要看得懂 → 选 CrewAI；
  • 团队已经用 LangChain → 优先 LangGraph，学习成本最低；
  • 不确定 → 先用 LangGraph 把 最小示例跑通，再按需换。

另外提醒：框架只是脚手架。真正的差距在工具设计、上下文管理和护栏——详见 工具调用指南和 记忆系统。

三个常见误区

  • 误区一："框架越火越安全"——框架不解决提示注入和工具滥用，那是你自己的护栏责任；
  • 误区二："多智能体一定比单智能体强"——多数任务单 Agent + 好工具就够了，多 Agent 的通信开销和失控面都更大；
  • 误区三："换了框架就要重写业务"——只要把工具、状态、记忆从业务代码里解耦，换框架就是换一层编排壳。

总结

LangGraph、AutoGen、CrewAI 的差别不在"能不能做 Agent"，而在你愿意用图、对话还是剧本的心智模型去管理那个标准 Loop。先想清楚场景需要哪种控制点，再选框架，而不是反过来被框架绑架。
