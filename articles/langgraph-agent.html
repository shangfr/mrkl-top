LangGraph 实战：用状态图构建你的第一个 Agent

前几篇文章讲的是概念，这篇动手。我们用 LangGraph 的 状态图（StateGraph）搭一个"查数据 → 计算 → 回答"的最小 Agent，并把它和标准 Agent Loop 一一对照，看显式状态图到底比 while 循环强在哪。

为什么用状态图而不是 while 循环

我们在 Agent Loop 原理里讲过：标准循环是一个隐式的 while，模型每轮输出决策，框架执行并回填。它的问题是——你很难在循环中间插手：想暂停、想人工审核、想回退一步，都得靠 hack。

LangGraph 把循环改成显式的有向图：每个节点是一段处理逻辑（思考、执行工具、总结），节点之间是边。于是循环的每一步都变成了图里可观测、可中断、可插入审核的位置。这个思路也正在被 OpenAI Agent SDK 等框架采用。

五个核心概念

概念作用对应标准 Loop 的…
State（共享状态）所有节点读写的数据对象（问题、观察、答案）上下文 + 历史轨迹
Node（节点）一段处理逻辑，读 State 并返回增量更新一轮"思考/行动"
Edge（边）定义执行顺序循环体的顺序执行
Conditional Edge（条件边）根据 State 分支，决定下一步走哪个节点模型判断"继续还是结束"
Checkpointer（检查点）保存每一步快照，可中断、可续跑持久化记忆

最小可运行示例

pip install langgraph langchain-openai
from typing import TypedDict
from langgraph.graph import StateGraph, END

class AgentState(TypedDict):
    question: str          # 用户问题
    observation: dict | None   # 工具返回的结果
    answer: str | None     # 最终答案

def decide(state):         # ① 思考节点：LLM 决定调用哪个工具
    # 真实实现里这里调用 LLM，解析出工具名与参数
    return {"observation": None}

def execute(state):        # ② 行动节点：执行工具并把结果写回状态
    return {"observation": {"price": 3310.5}}

def respond(state):        # ③ 终止节点：基于观察生成最终答案
    return {"answer": "最新收盘价是 3310.5"}

def route(state):          # 条件边：数据没齐就再执行一次，齐了就回答
    return "respond" if state["observation"] else "execute"

g = StateGraph(AgentState)
g.add_node("decide", decide)
g.add_node("execute", execute)
g.add_node("respond", respond)
g.add_edge("decide", "execute")
g.add_conditional_edge("execute", route, {"execute": "execute", "respond": "respond"})
g.add_edge("respond", END)

app = g.compile()
result = app.invoke({"question": "上证指数最新收盘价是多少？"})
print(result["answer"])

与标准 Agent Loop 的对照

标准 Agent Loop 环节LangGraph 中的落地
① 思考：LLM 生成决策decide 节点（LLM Node）
③ 行动：调用工具execute 节点（Tool Node）
④ 观察：结果写回上下文节点返回增量更新，合并进 State
② 是否结束条件边路由到 respond 或 END
⏱️ 迭代上限防死循环recursion_limit 参数
🧠 记忆 / 断点续跑Checkpointer（如 SqliteSaver）
👤 人工审核interrupt() 暂停并等待人类输入

三个实战要点

  • 设好 recursion_limit：防止模型钻牛角尖无限循环，等价于标准 Loop 的 max_iterations；
  • 用 Checkpointer 做长任务：耗时任务中途断掉可以从快照恢复，也天然获得对话历史；
  • 在敏感节点插 interrupt：比如"发送邮件"节点前暂停，由人来确认——这就是 Agent 安全护栏的落地姿势。

总结

状态图不是换一种写法，而是把隐式循环升级成可观测、可中断、可编排的执行引擎。理解了标准 Agent Loop，再看 LangGraph 就是"把每一步变成图里的节点"这么简单。
